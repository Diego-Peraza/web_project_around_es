Nombre del proyecto: Around the US
Descripción del proyecto: Página de inició para crear un listado de sitios turísticos. Cada elemento contiene una imagen, el nombre del sitio y un botón de "Me gusta". Se pueden eliminar todos los elementos y editar los elementos existentes.
La página contiene también un encabezado con el nombre del usuario y un texto con la ocupación del usuario. Estos dos elementos también son editables.

Descripción de las tecnologías usadas: La página ha sido creada usando HTML, CSS y JavaScript. Este proyecto en particular ha reforsado el uso de JavaScript y su interactividad con los elementos HTML, sus estilos, y la relación de los mismos en el DOM.
